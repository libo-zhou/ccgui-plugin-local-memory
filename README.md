# 项目记忆 (local-memory) 插件 🧠

为 **CC-GUI** 提供本地分层长期记忆系统。

## ✨ 特性

- 🧠 **专属图标**：插件标识与设置导航均统一采用 🧠 图标。
- 🌐 **双层架构**：
  - **项目专属记忆**：跟随工作区自动隔离，记录当前项目的技术栈、构建调试命令、目录规范、业务专有名词等。
  - **全局通用偏好**：记录个人通用习惯（如分支规范、提交要求、环境默认规则等），跨项目、跨会话生效。
- 📁 **全工作区支持**：
  - 设置页面中支持切换选择 CC-GUI 侧边栏中添加的**全部工作区**，即使是新加入的工作区也可以提前维护和配置项目记忆。
- 🤖 **对话自然语言自动记忆**：
  - 聊天时直接说：`请记住：本项目构建用 pnpm build` 或 `记住我不喜欢用 any`。
  - AI 会自然回复确认，并在后台通过私有协议帧隐式更新本地记忆库（界面无干扰）。
  - 支持删除记忆：`忘记关于...的记忆`。
- ⚡ **全会话自动注入**：
  - 无论是否选择智能体（Bot），无论是默认聊天还是任意引擎，每次发消息时都会将记忆无缝挂载到 System Prompt 中。
- ⚙️ **设置页集中管理**：
  - 在「设置 → 项目记忆」中集中管理记忆，支持多项目切换查看、手动添加、编辑修改、删除或复制为 Markdown。
- 🏷️ **底栏状态感知**：
  - 软件最底部的状态栏右侧实时显示：`🧠 记忆: 全局 X · 项目 Y`，点击可直接跳转到设置页进行管理。

---

## 📦 安装与热重载

1. 打开 **CC-GUI** 桌面客户端；
2. 点击左侧导航栏的 **「插件」**；
3. 点击右上角 **「从本地目录安装」**；
4. 选中当前插件目录：
   ```
   C:\Users\zhoulb600\ccgui-plugins\local-memory
   ```
5. 安装完成后，设置中即可看到「项目记忆」管理页面，软件最底部底栏右侧也会显示记忆状态项。
